# URLDL — آدرس دانلود

یک بازطراحی ساده و ریسپانسیو از رابط کاربری سایت «آدرس دانلود»؛
سرویسی برای نیم‌بها کردن لینک‌های دانلود.

این پروژه با هدف تمرین و پیاده‌سازی رابط کاربری مدرن با استفاده از
HTML و CSS ساخته شده و در ادامه JavaScript نیز به آن اضافه خواهد شد.

## 📌 About The Project

URLDL یک پروژه Front-End برای طراحی رابط کاربری یک سرویس نیم‌بها کننده
لینک‌های دانلود است.

در حال حاضر پروژه در مرحله طراحی اولیه قرار دارد و تمرکز فعلی روی
ساختار HTML، طراحی CSS و پیاده‌سازی Responsive Layout است.

JavaScript در مراحل بعدی پروژه برای اضافه کردن تعاملات و عملکردهای
مختلف استفاده خواهد شد.
